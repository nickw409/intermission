# Security policy

Intermission is a small, non-commercial hobby project. If you find a vulnerability, please report it
privately through GitHub: **Security → Report a vulnerability** on this repository (a private
security advisory). Please don't open a public issue for security problems.

Include what you found, how to reproduce it, and the impact you expect. You'll get an
acknowledgement as soon as the maintainer sees it; this is a one-person project, so please allow
some time for a fix.

In scope: the code in this repository and the public site built from it. Out of scope:
denial-of-service by volume, social engineering, and findings in third-party services
(Tailscale, TMDB, GitHub).
