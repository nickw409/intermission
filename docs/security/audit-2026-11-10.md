## 6. Method

- Each pass got the code and the threat model, not the authors' conclusions.
- Live testing used a staging stack of the audited images; auditors never ran `tailscale`.
- OWASP ZAP (`ghcr.io/zaproxy/zaproxy@sha256:9624669db72f54d86c4b46a7064518bd9bf79d8c61a4c31befa9923489f328af`): baseline, API scan from `contracts/public.yaml`, and an authenticated API scan; 121–122 active rules passed, 0 failed; every alert triaged.
- Trivy 0.69.3 (by digest) on all five images; govulncheck (source and binary); `npm audit`; gitleaks over all refs plus a grep of every reachable blob.
- Each fix went through the normal task protocol: test first, independent code review, test validation with mutation testing, re-test by the auditor who found it.
